# Retail-Sales-Analysis
Interactive retail sales dashboard and business performance analysis using Microsoft Excel.

## Project Overview
An interactive U.S. retail sales dashboard developed in Microsoft Excel to analyse multi-year sales performance, order volume, and profitability (2014–2017) across regions, product categories, and customer segments.


## Objectives
- Analyse overall sales performance.
- Identify top-performing product categories.
- Evaluate profit margins.
- Compare sales across different segments.
- Track key performance indicators (KPIs).

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- KPI Cards
- Data Cleaning

## Dashboard Features
- Interactive filtering using slicers.
- Dynamic KPI calculations.
- Sales and profit analysis.
- Category-level performance comparisons.
- Profit margin monitoring.

## Key Learnings
- Data cleaning and preparation.
- Business data analysis.
- Dashboard development.
- Interactive reporting.
- Translating data into business insights.
